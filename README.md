# Kiral Aris

## How do I install these formulae?

`brew install kiral/aris/<formula>`

Or `brew tap kiral/aris` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kiral/aris"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
